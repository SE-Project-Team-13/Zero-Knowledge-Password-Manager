# 🔐 Zero-Knowledge Password Manager

A production-ready password manager built with zero-knowledge architecture. Your master password and decrypted data **never leave your device**. The server only sees encrypted data it cannot read.

## 🛡️ Security Model

```
┌──────────────────────────────────────────────────────┐
│ 1. Login → Server verifies credentials (no password) │
│ 2. OTP → Email verification sent                     │
│ 3. Fetch → Server returns encrypted vault            │
│ 4. Decrypt → Browser decrypts with master password   │
│ 5. Memory → Passwords stored in RAM only             │
│ 6. Modify → Edit/add passwords locally               │
│ 7. Encrypt → Re-encrypt and sync to server           │
└──────────────────────────────────────────────────────┘
```

**Crypto Stack:**
- `Argon2id` (via @noble/hashes) - Key derivation
- `AES-256-GCM` (Web Crypto API) - Symmetric encryption
- `SHA-256` - Hashing and integrity checks

## 🚀 Quick Start

### Using Docker (Recommended)

```bash
# 1. Clone repository
git clone <your-repo-url>
cd Password_Manager

# 2. Configure environment
# Create packages/backend/.env with:
MONGODB_URI=mongodb://admin:password@mongodb:27017/password-manager?authSource=admin
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-gmail-app-password
SMTP_FROM="Password Manager" <your-email@gmail.com>

# 3. Start everything
docker-compose up -d

# Services available:
# - Frontend: http://localhost:3000
# - Backend: http://localhost:3001
# - MongoDB: mongodb://localhost:27017
```

### Manual Setup

**Prerequisites:** Node.js 18+, MongoDB

```bash
# Install dependencies
npm install

# Configure environment
# Create packages/backend/.env with MongoDB URI and SMTP credentials

# Start backend
cd packages/backend && npm run dev

# Start frontend (in new terminal)
npm run dev

# Build extension
cd packages/extension && node build.js
# Load unpacked extension from packages/extension/dist in Chrome
```

## 🔧 CI/CD Pipeline

**GitHub Actions** automatically:
1. Runs 42 tests on every push
2. Builds Docker images
3. Performs code quality checks
4. Pushes images to Docker Hub (on main/karthik/ladda branches)

**Setup GitHub Secrets:**

Go to `Settings → Secrets and variables → Actions → New repository secret`

Required secrets:
- `DOCKER_USERNAME` - Docker Hub username
- `DOCKER_PASSWORD` - Docker Hub access token (get from https://hub.docker.com/settings/security)
- `SMTP_USER` - Gmail address
- `SMTP_PASS` - Gmail app password (get from https://myaccount.google.com/apppasswords)

## 📧 Environment Configuration

Create `packages/backend/.env`:

```env
# MongoDB
MONGODB_URI=mongodb://admin:password@mongodb:27017/password-manager?authSource=admin

# Server
PORT=3001
NODE_ENV=development

# SMTP (Gmail)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-gmail-app-password
SMTP_FROM="Password Manager" <your-email@gmail.com>
```

**Gmail App Password Setup:**
1. Enable 2FA on your Gmail account
2. Visit https://myaccount.google.com/apppasswords
3. Select "Mail" and generate password
4. Copy 16-character password to `SMTP_PASS`

## 🔒 Security Features

- **Zero-knowledge encryption** - Server cannot decrypt data
- **Client-side key derivation** - Argon2id with high memory cost
- **Authenticated encryption** - AES-256-GCM with AEAD
- **SRP-style authentication** - Password never transmitted
- **OTP verification** - Email-based 2FA
- **Auto-lock** - Vault locks after inactivity
- **Memory-only storage** - Decrypted data never touches disk

## 📦 API Endpoints

### Authentication
- `POST /auth/register` - Register new user
- `POST /auth/login` - Login with credentials
- `POST /auth/salt/:email` - Get user salt

### OTP
- `POST /otp/send` - Send OTP to email
- `POST /otp/verify` - Verify OTP code

### Sync
- `POST /sync/push` - Push encrypted vault
- `GET /sync/pull/:userId` - Pull encrypted vault
- `GET /sync/metadata/:userId` - Get sync metadata
